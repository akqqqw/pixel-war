# Мировое господство: Pixel War

Браузерная 2D pixel-art военная глобальная стратегия: карта мира из регионов, три государства,
экономика, производство современной техники, переброска войск и захват территорий.
Игра написана на TypeScript + React + Phaser 3 + Zustand + IndexedDB и полностью работает локально.

**Текущий статус: этап 1 — играбельный прототип.** Реализованы карта, государство, экономика,
производство, движение войск, бои за территории, ИИ-противники и экран победы/поражения.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # tsc --noEmit + production-сборка Vite
npm test           # Vitest: логика, отрисовка, UI
npm run typecheck
```

## Что уже играется (этап 1)

- **Процедурная карта мира**: 128×80 тайлов по 8 px (32×32 «крупный тайл» для чтения карты),
  28 регионов, 3 государства с разными цветами и столицами, море и острова, реки и 6 типов рельефа.
  Каждый регион имеет население, экономический профиль и уровень инфраструктуры.
- **Экономика**: деньги, металл, нефть, энергия. Доход считается по регионам и рельефу,
  содержание армии вычитается каждый час. Ресурсы никогда не уходят в минус; дефицит замедляет
  производство, марши и восстановление.
- **Производство**: 6 типов наземной техники (ОБТ, лёгкий танк, БТР, БМП, САУ, РСЗО) с ценой,
  временем постройки, атакой, бронёй, дальностью. Очередь до 3 единиц на территорию,
  отмена с возвратом 60 % стоимости, скидка от уровня инфраструктуры.
- **Армия**: гарнизоны регионов, формирование отрядов, марш по своей территории с временем в пути,
  подкрепления, объединение и разделение частей.
- **Бои**: пошаговая симуляция до 12 раундов с учётом рельефа, обороны, бронетехники и случайности;
  прогноз шансов до отправки; отчёт о бое с таблицей раундов и потерями.
- **Захват регионов**: пустой регион переходит без боя, защищённый — только после победы;
  атака чужой территории автоматически объявляет войну. Потеря столицы переносит её,
  потеря всех земель уничтожает государство.
- **ИИ**: три уровня сложности. ИИ получает те же ресурсы и приказы, что и игрок,
  развивает экономику, строит технику, стягивает гарнизоны к фронту и атакует при выгодном
  соотношении сил.
- **Победа и поражение**: мировое господство (все регионы) или уничтожение противников;
  поражение при потере всех территорий.
- **Сохранения**: IndexedDB, автосохранение каждые 30 игровых часов (30 секунд игры) и при выходе,
  ручные сохранения, загрузка из главного меню.
- **Интерфейс**: главное меню, выбор государства и сложности, верхняя панель ресурсов и даты,
  левая панель (армия, экономика, дипломатия, журнал), правая панель региона, нижняя панель
  скорости и приказов, мини-карта, обучение, настройки, полноэкранный режим.
  Адаптивная вёрстка для телефонов и планшетов (выдвижные панели).

## Управление

| Действие | Управление |
| --- | --- |
| Движение карты | перетаскивание мышью или пальцем |
| Масштаб | колесо мыши, щипок, кнопки «+»/«−» на мини-карте |
| Выбор региона | клик/тап по территории |
| Пауза | Пробел |
| Скорость | 1 / 2 / 3 → ×1 / ×2 / ×4 |
| Закрыть окно/панель | Esc |
| Сохранить | Ctrl+S |

## Архитектура

```
src/
  core/            чистая игровая логика без Phaser и React
    world/         генерация мира, рельеф, регионы, морские зоны
    countries/     государства и их параметры
    units/         типы техники и операции над армиями
    economy/       доход, содержание, уровни инфраструктуры, волнения
    combat/        расчёт боя и прогноз
    sim/           часовой цикл, приказы, производство, пути, события, победа
    ai/            ИИ-противники (те же приказы, что и у игрока)
    save/          сериализация состояния
  data/            статические данные: страны, названия регионов
  game/            слой Phaser: сцены, спрайты, эффекты, камера, рендер-текстуры
  store/           Zustand-хранилище и игровые действия
  services/        IndexedDB-сохранения
  ui/              React-интерфейс: меню, HUD, диалоги, стили
  tests/           Vitest-набор: мир, бои, экономика, приказы, симуляция, сохранения, UI, пиксель-арт
```

Правила, которые соблюдаются в коде:

- `core` не импортирует Phaser и React; рендер и UI зависят от `core`, но не наоборот.
- Все действия игрока и ИИ проходят через одни и те же приказы в `core/sim/commands.ts`.
- Ресурсы — только неотрицательные числа; любая трата проверяется до применения.
- Спрайты рисуются кодом (pixel-art на canvas) и подменяются PNG без изменения логики.
- Состояние партии сериализуется полностью, версия сохранения проверяется при загрузке.
