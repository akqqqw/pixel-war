# Мировое господство: Pixel War

Браузерная 2D pixel-art стратегия о захвате мира: карта из 28 регионов, три государства,
экономика, постройки, армия и фронт, который двигается по правилам «Жизни» Конвея.
Стек: **TypeScript + Vite + React + Phaser 3 + Zustand + IndexedDB + Vitest**.
Игра полностью работает локально в браузере, без сервера.

**Текущий статус: переработанный прототип (этап 2).** Огромные панели убраны: на экране карта,
тонкая верхняя строка и **одна нижняя панель с тремя вкладками — Экономика / Оружие / Безопасность**.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # tsc --noEmit + production-сборка Vite
npm test           # Vitest: мир, экономика, постройки, фронт, симуляция, сохранения, UI
npm run typecheck
```

## Как играть

1. **Меню → Новая игра** → выберите государство и сложность.
2. Щёлкните по своей территории на карте — в нижней панели появятся её цифры и действия.
3. На вкладке **Экономика** выберите постройку и щёлкните по своей территории, чтобы поставить её.
4. На вкладке **Оружие** строятся ракетная установка, завод сборки танков и взлётная площадка.
5. На вкладке **Безопасность** — ПВО и баррикада: у обеих есть радиус действия,
   он рисуется прямо на карте вокруг каждой своей постройки.
6. Кнопка **Призвать** превращает население в армию, **Перебросить** — переводит половину
   гарнизона в соседнюю свою территорию. На чужой территории доступны **Объявить войну** и **Мир**.

Управление: колесо/щипок — масштаб, перетаскивание — карта, `Space` — пауза, `1/2/3` — скорость
(×1/×2/×4), `Esc` — отмена выбора, `Ctrl+S` — сохранить.

## Правила

### Экономика

- Один час игры = один тик (в реальном времени — 1 секунда при ×1).
- Доход территории = налог с населения + доход построек; из дохода страны вычитается содержание армии.
- Казна не уходит в минус: если содержание не по карману, армия распускается (потери 3 % в час).
- **Город** растит население и поднимает его предел, **завод** и **морской порт** дают деньги.

### Армия

- Армия — это просто число; спрайтов и моделей юнитов нет.
- Найм идёт из населения: один солдат забирает 0,4 тыс. человек и стоит 6 ₽.
- Предел гарнизона — 6 % населения территории, поэтому города косвенно увеличивают армию.

### Захват территорий по правилам «Жизни»

- Клетки карты меняют владельца только между странами **в состоянии войны**.
- Армия даёт «бюджет» переворотов: `(атака − оборона) / 8`, не больше 3 клеток
  с одной границы за тик. Оборона считается из гарнизона, населения, рельефа и построек.
- Клетка рождается в чужой стране, если у неё **3+ соседа** этой страны;
  клетка голодает и переходит к соседям, если у неё **≤1 своего** соседа и **2+ чужих**.
- Захватчик платит 1 армию за клетку, защитник теряет 0,6 армии и 0,4 % населения.
- Оборона = (гарнизон × 0,6 + население × 0,02) × рельеф × (1 + бонус ПВО/баррикад).
- Территория переходит целиком, когда новая страна занимает **55 %** её клеток:
  половина построек разрушается, население падает на 15 %, в регион входит 30 % армии с границы.
- Потеря последней территории уничтожает государство; потеря столицы переносит её.

### Постройки (одна панель, три вкладки)

| Вкладка | Постройка | Цена | Эффект |
| --- | --- | --- | --- |
| Экономика | Город | 260 ₽ | +2 ₽/ч, +2,5 тыс. населения/ч, предел населения +3000 |
| Экономика | Завод | 220 ₽ | +4 ₽/ч |
| Экономика | Морской порт | 320 ₽ | +6 ₽/ч (только на побережье) |
| Оружие | Завод сборки танков | 380 ₽ | +0,6 армии/ч |
| Оружие | Ракетная установка | 420 ₽ | автоматические удары по врагу в радиусе 2 территорий |
| Оружие | Взлётная площадка | 400 ₽ | +0,25 армии/ч, +25 % к атаке своей и соседних территорий |
| Безопасность | ПВО | 320 ₽ | радиус 6, +20 % обороны, сбивает 70 % ракет |
| Безопасность | Баррикада | 200 ₽ | радиус 4, +35 % обороны |

Итого восемь построек с лимитами на территорию. Радиус ПВО и баррикады считается по клеткам
карты и складывается (не больше +50 % обороны), поэтому постройка у границы прикрывает
и соседний регион. Всё, что видно в панели, действительно работает.

### ИИ

Три профиля сложности отличаются интервалом решений, агрессивностью и временем до первой войны.
ИИ живёт по тем же правилам: платит за постройки и найм, ограничен населением и содержанием,
не получает бесплатных ресурсов. Он развивает экономику, стягивает армию к слабейшему участку
границы и объявляет войну, только когда его войска на границе заметно сильнее обороны цели.

## Сохранения

- IndexedDB `pixel-war` → хранилище `saves`; автосохранение каждые 40 тиков и при выходе в меню.
- Ручное сохранение — `Ctrl+S` или меню (`MenuDialog`). Загрузка — «Продолжить» в главном меню.
- Сейв — это JSON (`SAVE_VERSION = 2`) с картой клеток; при загрузке значения проверяются,
  отрицательные деньги/армия/население и битые ссылки на страны исправляются, а не загружаются.
- Если IndexedDB недоступен, включается резервное хранение в памяти, игра не падает.

## Архитектура

```
src/core      — вся логика без DOM: world/ (генерация карты), state/, sim/ (экономика,
                фронт, действия, ракеты, победа, симуляция), ai/, buildings/, save/
src/game      — Phaser: сцены, painter тайлов, текстуры, камера (только отрисовка)
src/data      — описания государств и имена регионов
src/store     — Zustand: состояние экранов, игровой цикл, действия UI
src/services  — IndexedDB-сохранения
src/ui        — React: одноэкранный HUD, нижняя панель, диалоги, меню
src/tests     — Vitest: 7 файлов, 55 тестов
```

Правила: логика не импортирует Phaser и React; карта рисуется процедурными пиксельными
текстурами (nearest-neighbour, тайл 8 px, крупный «клеточный» шаг 32 px), поэтому PNG можно
заменить без изменения логики. Все числа баланса собраны в `src/core/sim/balance.ts`.
