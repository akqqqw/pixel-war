# Pixel World War — Мировая война в пикселях

Браузерная 2D pixel-art стратегия: карта мира разбита на клетки, три государства делят
землю, а игрок ведёт армию по клеткам, строит экономику, оружие и оборону.
Стек: **TypeScript (strict) + Vite + React + Phaser 3 + Zustand + IndexedDB + Vitest**.
Игра работает полностью локально, без сервера и без внешних SDK.

**Статус: этапы 1–7 готовы** — интерфейс, экономика, клеточный захват, оружие, безопасность,
ИИ и баланс, производительность и мобильная раскладка.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # tsc --noEmit + production-сборка
npm test           # Vitest
npm run typecheck
```

## Как играть

1. **Меню → Новая игра** → государство и сложность.
2. Нажмите на **свою клетку**. Внизу справа появится компактная карточка клетки:
   армия, оборона, постройка, кнопка **Мобилизация**.
3. **Наступление.** Выберите свою клетку, затем **вражескую** — появится ползунок
   «Отправить армию: 10–100 %». Подтвердите: солдаты пойдут к границе и сами начнут
   бой за соседние клетки. Там же — «Стоп» и «Отойти».
4. **Экономика / Оружие / Безопасность** — три вкладки в нижней панели. Вкладка открывает
   короткую полосу построек; выбранная постройка ставится кликом по своей клетке.
5. Постройку на выбранной клетке можно **улучшить** или **удалить** в карточке клетки;
   у ракет и авиации там же кнопка удара — затем клик по вражеской клетке.

Управление: колесо/щипок — масштаб, перетаскивание — карта, `Space` — пауза,
`1/2/3` — скорость ×1/×2/×4, `Esc` — отмена режима, `Ctrl+S` — сохранить.
Интерфейс — три тонкие плашки (верх, низ, карточка клетки), карта занимает весь экран.
Наведение на клетку показывает однострочную подсказку; скрытая вкладка браузера
автоматически ставит игру на паузу и возвращает прежнюю скорость при возврате.
Звук (🔊 в верхней строке или в меню партии) — синтез WebAudio без файлов: захват и потеря
клеток, пуск ракеты, стройка, мобилизация, победа и поражение. Первый тап разблокирует аудио.

## Правила

### Клетки

- Каждая клетка хранит владельца, армию, укрепление, рельеф и постройку.
- Море захватить нельзя: бои идут только по суше между соседними клетками.
- Границы рисуются по перепадам владельцев — никаких заранее нарисованных линий.

### Бой (тик — 0,5 с)

1. Для каждой клетки на границе собираются соседи-противники, с которыми идёт война.
2. Атака клетки — `гарнизон × 0,6`, деньги делятся между всеми вражескими соседями,
   поэтому одна клетка не может атаковать двух противников одной и той же армией.
3. Оборона — гарнизон × (1 + танки) × (1 + укрепление) × рельеф + ополчение.
4. Клетка переходит attacker'у только если атака больше обороны с запасом 5 %;
   при провале обе стороны теряют солдат.
5. Все результаты тика считаются по одному снимку карты и применяются одновременно.

### Наступление

- Приказ запоминает регион-источник, цель и долю армии.
- Каждый тик все свои клетки отправляют часть гарнизона на шаг к цели —
  войска стягиваются к острию, а не стоят по всей стране.
- Один солдат за тик двигается только на одну клетку, поэтому армия не дублируется.
- После захвата приказ сам выбирает следующую ближайшую цель; если упёрся в мир или
  потерял фронт — ищет другое направление, а без вариантов завершается.

### Экономика

- Доход = налоги с населения + постройки − содержание армии.
- Казна не уходит в минус: при нехватке денег армия расходится.
- **Город** (800) — население и его предел, **Завод** (500) — золото,
  **Порт** (1200) — много золота, только у воды.
- **Мобилизация** превращает людей региона в солдат за золото, с кулдауном и лимитом;
  потерянные солдаты в население не возвращаются.

### Оружие и безопасность

- **Ракетная установка** (1400, радиус 24) — удар по выбранной клетке, перезарядка, уничтожается.
- **Завод сборки танков** (900) — копит танки за золото: бонус к атаке и обороне.
- **Взлётная площадка** (1100, радиус 20) — самолёты, авиаудары и бонус к атаке рядом.
- **ПВО** (1000, радиус 8) — перехват 70 %, радиусы складываются по формуле `1-(1-p)^n`, предел 90 %.
- **Баррикада** (400, радиус 4) — +35 % обороны в радиусе, движение не блокирует.
- Юнитов-спрайтов нет: армия, танки и самолёты — числа; удары рисуются пиксельной вспышкой.

### ИИ

- Те же правила и цены: никаких бесплатных ресурсов.
- Сложность меняет качество решений (частота, порог риска, набор построек), а не бонусы.
- ИИ строит города/заводы/танки/оборону, мобилизует армию, объявляет войны,
  ведёт наступления, бьёт ракетами и самолётами, заключает мир при слабости.

### Итоги кампании

- Каждые 20 тиков игра записывает долю земли каждого государства — это «ход войны».
- График виден в меню партии и на экране победы/поражения (`Sparkline`, чистый SVG).
- Хранятся последние 180 точек; старые отбрасываются, сейв не растёт.

### Победа

- Захватить всю землю — «Мировое господство».
- Уничтожить всех соперников — «Военная победа».
- Потерять все клетки — поражение.

## Архитектура

```
src/core/world      карта, регионы, клетки, рельеф
src/core/state      типы состояния, createGame, sanitizeGame
src/core/sim        balance, effects, regions, economy, battle, army, orders,
                    strikes, actions, diplomacy, victory, simulation, events
src/core/buildings  восемь построек, стоимости, эффекты
src/core/ai         решения ИИ по профилям сложности
src/core/save       сериализация (cellOwner / cellArmy / приказы / удары)
src/game            Phaser-сцена, камера, текстуры, пиксельные глифы
src/ui              меню, HUD (TopBar, BottomPanel, CellPanel, OrderPanel), модалки
src/store           Zustand-стор: единственный вход для интерфейса
src/services        IndexedDB-сохранения, автосейв
src/tests           Vitest: мир, экономика, клетки, приказы, сохранения, стор, UI
```

- Логика не знает о рендере: сцена только читает состояние стора.
- Нет React-компонента на клетку — карта рисует Phaser одним слоем владельцев.
- Тик боя фиксирован (0,5 с), рендер — на частоте кадров.
- Сохраняются владельцы клеток, армии, экономика, постройки, приказы, ИИ-состояние и время.
- Перерисовка карты включается счётчиком `mapVersion` (O(1)), а не сравнением всей карты.
- Один тик логики на полной карте — около 1 мс при бюджете 500 мс (`tests/performance.test.ts`).
- Фронт виден на карте: жёлто-оранжевые искры на клетках, где в этот тик шёл бой,
  и вспышка на захваченных клетках.

## Сохранения

IndexedDB (с fallback в память, если браузер запретил хранилище), автосохранение каждые
40 тиков и при выходе. После перезагрузки страницы партия восстанавливается из автосейва.
Схема сохранения версионирована (`SAVE_VERSION`), сломанные поля чинятся при загрузке.
